# Getting started with LAG

LAG helps you practise the LAG1201 German vocabulary and grammar from *Das Leben
A1*, Units 0–7. You type your answers, check the course forms, and retry anything
that needs work. No account is required.

Open the LAG app in your browser. If you are running the repository yourself,
follow [Run locally](../README.md#run-locally) first.

## Your first quiz

1. Under **Chapters**, select the units you want to practise. Use **Clear** to
   start with one chapter, or **Select all** for a broader review.
2. Choose **Mixed practice** for vocabulary and grammar together.
3. Set **Questions** to **10** for a short session.
4. Under **Feedback**, choose **After each answer** to learn as you go.
5. Select **Start practice**.

The start bar shows the actual question count. If your selection has fewer
distinct items than requested, the quiz uses the available items. Changing the
practice focus keeps your chapter selection.

## Choose a practice focus

| Focus | What you practise |
| --- | --- |
| **Mixed practice** | Vocabulary and grammar together |
| **Vocabulary** | Meanings, German words, noun articles and plurals |
| **Grammar** | Sentence patterns, word order and chapter-specific rules |
| **Conjugation tables** | A verb's forms for all seven pronoun rows |
| **Semester Test 1** | Listening, reading, articles, verbs, questions, negation and syntax |

Open **Custom question mix** to combine individual question types.

**Semester Test 1 covers Units 0–4 only.** Select all five of those chapters for
access to every section. Selecting only Units 5–7 with this focus produces no
questions. These are randomized practice tasks, not a timed paper or the
official test marking scheme.

## Choose when to see feedback

- **After each answer (Study mode):** select **Check answer**, read the correction,
  explanation and source, then choose **Next question** or **See results**.
- **At the end (Exam mode):** select **Submit answer** to move straight to the next
  question. Scores and corrections appear after the quiz.

For a text question you cannot answer, select **I don’t know**. It counts as
unanswered for zero points. Study mode shows the correction immediately; Exam
mode saves it for the end.

## Enter answers in the requested format

Read the instruction above each question. Some questions ask for one word;
others require a complete sentence or several answers.

| When asked for… | Example answer |
| --- | --- |
| A noun's article | `der` |
| A complete singular noun | `der Briefkasten` |
| A complete plural noun | `die Briefkästen` |
| Singular and plural together | `der Briefkasten, die Briefkästen` |
| A form the glossary does not list | `X` in that position, such as `der Stress, X` |
| Two blanks, in order | `lädt, ein` |
| Matching people in a reading task | `Anna, Clara`, or `Niemand` if nobody matches |

Include articles, capital letters and punctuation when requested. Use the
**Insert** buttons for ä, ö, ü, ß, Ä, Ö and Ü. They insert at the cursor in the
last answer field you used.

For listening tasks, use the audio player to pause and replay the recording.
Keep leading zeros in telephone numbers; spaces between digit groups are allowed.

### Conjugation tables

Fill the rows for **ich**, **du**, **er / sie / es**, **wir**, **ihr**,
**sie (they)** and **Sie (formal)**. Type the verb form without the subject
pronoun: for example, `komme` in the **ich** row.

Include detached prefixes or reflexive pronouns when the instruction calls for
them: `fährst ab` or `freue mich`. Leave an unknown row blank and submit the
table to review it. One table counts as one question; its seven rows contribute
equally to that question's score.

## Understand your score and review

Each question is worth up to one point. Exact answers earn full credit.
For ordinary text answers, capitalisation-only mistakes earn 0.75 points;
German-character substitutions and small typos can earn 0.5 points.
Incorrect answers and skipped questions earn zero. Wrong telephone digits,
missing reading matches and another person's conjugation form are not treated
as spelling typos.

On the results screen:

- **Needs practice** shows answers that lost points, including partial answers.
- **All answers** includes the ones you got right.
- **Retry missed forms** starts a quiz with the questions that lost points.
  This button appears only when there are missed forms.
- **New quiz** returns to setup so you can change chapters or focus.

The home screen's accuracy includes partial credit and reflects all recorded
answers on this browser, including retries.

## Saved progress and offline use

LAG remembers your setup choices and submitted-answer progress in this browser.
Progress does not sync between browsers or devices. Clearing site data removes
it; private browsing or blocked storage may prevent it from being retained.

The current quiz and its results are not saved across a page refresh. Finish
your quiz and review before reloading. Answers already submitted still count
toward your saved progress.

For offline use, first open LAG while connected and wait until the header says
**Available offline**. You can then practise using the cached content and sample
recordings. **Online** alone does not confirm that offline setup has finished.

When **Reload app** appears, finish your quiz and review before selecting it.
Reload while online to receive updates; saved progress is retained.
